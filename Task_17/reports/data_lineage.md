# Task_17数据血缘说明

## 1. 数据来源

Task_17使用两个GlobeLand30 2020原始图幅：

```text
N48_20_2020LC030
N49_20_2020LC030
```

每个原始包包含30 m分类GeoTIFF、TFW坐标文件、MAT XLS元数据，以及Landsat影像索引Shapefile及其配套文件。两包共18个文件，入库时逐文件计算SHA256并与外部原件比较。

源MAT记录产品由自然资源部发布、国家基础地理信息中心分发，产品年代为2020，总体精度85.72%。影像索引记录的基础Landsat 8日期跨2015—2017年，因此“2020”表示产品版本/更新年代，不等于每个基础影像的拍摄年份。

## 2. 分类元数据

两份原始MAT均定义10个一级类别以及`0=无值`、`255=海水`。当前Conda环境没有GDAL旧版XLS插件，未为解析两张小型元数据表而增加二进制依赖。

处理采用以下可审计方式：

1. 原始XLS不修改、完整保存并计算SHA256；
2. 人工核对两份MAT内容一致；
3. 将类别编码、中英文名称和调色板转录为`landcover_class_lookup.csv`；
4. 自动检查源栅格和结果栅格的编码只能来自该字典。

## 3. 空间处理链路

```text
GlobeLand30 N48（EPSG:32648）
  ┐
  ├→ 最近邻映射到Task_14广西Albers 30 m网格
  ┘       → 按108°E名义分幅线选择来源
GlobeLand30 N49（EPSG:32649）
          → Task_01南宁市边界裁剪
          → 30 m分类COG
          → Task_05统一1 km网格统计
          → Task_01南宁市12县区汇总
```

分类变量只使用最近邻，不进行双线性、三次卷积或类别平均。目标栅格直接复用Task_14的宽、高、transform、范围与CRS，从而与DEM和Task_15坡度逐像元对齐。

## 4. 重叠区规则

两幅UTM图幅的矩形覆盖范围在108°附近重叠。Task_17依据产品名义经度范围确定来源：

- `lon < 108°`：N48；
- `lon >= 108°`：N49。

重叠区两幅数据的相同/不同像元和类别转移矩阵单独写入`overlap_analysis.json`。冲突报告用于表达来源敏感性，不生成新类别，也不将两类做数值平均。

实际复投影后有3,683,627个重叠像元在两幅数据中均有效，共171,456个类别不同，冲突率4.6545%。该指标仅表示两图幅在重叠区的分类差异，不等同于南宁市整体分类误差。

## 5. 统计关系

- 空间主键：Task_05稳定`grid_id`。
- 行政主键：Task_01稳定`county_adcode`。
- 网格宽表：一格一行，便于SmartBI和模型直接连接。
- 网格长表：一格固定10类，便于按类别筛选和透视分析。
- 县区长表：每县固定10类，直接按县区几何统计，不用主县规则强制分配跨县网格。

最终分类栅格有24,550,563个有效像元。该总数与网格长表、县区长表的类别像元总数一致；网格宽表的10类比例仅对有效像元归一化。

## 6. 适用限制

该数据表达遥感地表覆盖，不表达土地所有权、使用权、规划用途或审批状态。下游若把类别归并为不透水面、植被、水体等洪涝指标，必须单独记录映射、权重和版本。
