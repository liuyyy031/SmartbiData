# 南宁市公共服务设施坐标数据

本目录用于提供可直接导入 SmartBI 的南宁市医院、学校和养老机构点位数据。

原始数据来自仓库中的医院、学校和养老机构数据表。原始文件保持不变，本目录仅生成项目范围内的兼容副本。

## 文件说明

| 文件 | 数据内容 | 记录数 |
| --- | --- | ---: |
| `hospitals_nanning.csv` | 南宁市医院及医疗机构 | 85 |
| `schools_nanning.csv` | 南宁市学校及教育机构 | 562 |
| `elderly_homes_nanning.csv` | 南宁市养老机构 | 91 |

## 坐标字段

- `longitude`：经度，数值型；
- `latitude`：纬度，数值型；
- 坐标系：WGS84（EPSG:4326 / OGC:CRS84）；
- 经度、纬度均使用十进制度数。

医院和学校数据从广西范围的原表中按照 `city = 南宁市` 筛选；养老机构原表本身即为南宁市范围，因此保留全部记录。

## SmartBI 导入设置

导入 CSV 后，请将 `longitude` 和 `latitude` 两个字段的数据类型设置为“数值型”或“浮点型”，不要设置为字符串。

地图组件中：

- 经度字段选择 `longitude`；
- 纬度字段选择 `latitude`；
- 名称字段分别选择 `facility_name` 或 `name`；
- 区县字段选择 `district`。

## 质量检查

- 三份数据均保留原始业务字段；
- 经度、纬度缺失记录数均为 0；
- 所有坐标均可解析为数值；
- 所有坐标均处于广西合理经纬度范围内；
- 未覆盖或修改仓库中的原始医院、学校和养老机构文件。
