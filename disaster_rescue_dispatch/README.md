# 灾中救援与应急调度数据

本目录保存任务三灾中救援分析、SmartBI数据模型、仪表盘及地图展示所使用的最终派生数据。

## 目录说明

- smartbi_tables：SmartBI导入使用的CSV表；
- map_layers：救援路线、人员转移路线、救援资源点、避难场所等地图图层。

## 坐标说明

地图数据统一采用WGS84坐标系（EPSG:4326）。

- longitude：经度，数值型；
- latitude：纬度，数值型。

路线数据按照route_id分组，并按照point_order排序后依次连接。

## 数据说明

数据由淹没范围、人口、道路、居民点、重点设施和救援资源等数据经过空间叠加、清洗和调度计算生成，用于区县影响分析、救援优先级排序和路线展示。
