# Task_19数据血缘说明

## 1. 来源链路

2016—2023年广西水旱灾害公报PDF
→ 文件大小与SHA256核验
→ PDF页数、加密状态和文本层检查
→ 含“南宁”及洪涝关键词的85个候选页
→ 人工辨识独立事件并记录证据页和原文锚点
→ 事件、证据、行政区关系、影响指标四张规范表
→ 年度与县区频次下限

2022年WPS原件保留用于来源追溯，正式抽取以对应PDF为准。2024年水资源公报不属于同类灾害公报，未混入历史洪涝频次；2025年缺少来源。

## 2. 人工目录与自动复核

`config/nanning_flood_event_catalog.json`是人工复核后的事件事实目录。每个事件必须包含唯一`event_id`、日期、灾害类型、南宁相关性和至少一条证据。构建脚本不利用关键词自动生成事件，而是完成以下约束检查：

- 事件编号、来源年份和开始日期一致；
- `direct_affected`与计频标志严格对应；
- 证据页不超出PDF页数；
- 页内锚点经过全半角与空白归一化后必须在原页文本中出现；
- 证据记录携带原始公报SHA256；
- 县区代码和名称必须与Task_01一致；
- 指标值非负，南宁专属标志与指标空间范围一致。

这种结构把“候选发现”和“事实确认”分开，避免把同一事件在综述、表格和专题中的多次出现重复计数。

## 3. 行政区和邻近范围

县区频次几何直接复用Task_01的南宁12县区边界，坐标系为EPSG:4490。邻近地区清单由Task_06广西县界在统一投影下计算边界接触关系，并用100米容差处理细微几何缝隙。

当前识别的邻接地级市为防城港、钦州、贵港、百色、河池、来宾、崇左，共7个。清单同时保留15个直接邻接县级单元。该关系用于判断周边事件是否值得标注，不会自动把邻市灾情归入南宁市。

## 4. 频次派生

年度频次只统计`included_in_nanning_frequency=true`的事件。周边气象、水文和邻近灾情分别计入`context_event_count`，不进入`direct_affected_event_count`。

县区频次进一步要求行政区关系为`affected`。明确超警河段或监测点使用`monitoring_location`，不会被当成县区受灾证据。没有明确县区证据的南宁市级事件也不会按面积、主县或均分规则下派到12县区。

## 5. 影响指标血缘

每条影响指标通过`evidence_id`关联到公报原页。`impact_scope_level`记录指标属于南宁、南宁县区、多市合计、全广西或其他范围，`is_nanning_specific`提供机器可读的使用限制。

多市合计值原样保留，是为了表达事件规模和公报证据，但不能在下游图表中标为“南宁市受灾人口”或“南宁市经济损失”。当前南宁专属值仅来自良庆区南晓镇专题记录。

## 6. 缺失值语义

- 2024—2025年年度频次为空：来源不可用，不表示零次。
- 县区频次为0：现有2016—2023年公报未明确点名，不表示无灾。
- 空的南宁专属损失：没有足够粒度证据，不允许从多市合计数推算。

后续若补充地方应急通报、县区年鉴、新闻或遥感洪水图斑，应新增来源类型和证据记录，并保留原有公报口径，不能无痕覆盖本版本。
